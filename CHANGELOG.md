### Security
- **Scanner Bot Blackhole**: Added regex-based location filters in Nginx to immediately drop common vulnerability scans (WordPress, PHP, CGI, ASPX, Python) and sensitive dotfile requests (e.g. `.env`, `.git`) with a `444` (Connection Closed Without Response) status, conserving bandwidth and server resources in production without affecting valid API endpoints.
- **CSRF Double-Submit Protection**: Added a pure-ASGI `CSRFMiddleware` ([middleware.py](file:///home/user/Luma/backend/luma/middleware.py)) implementing the double-submit cookie pattern. Every state-mutating request must echo the non-HttpOnly `csrf_token` cookie back in an `X-CSRF-Token` header; HAE ingest endpoints (header/token authenticated, non-browser) are exempt. The frontend API client ([api.ts](file:///home/user/Luma/frontend/src/lib/api.ts)) attaches the header automatically and exposes `csrfHeaders()` for the raw-fetch call sites (coach streaming, photo upload).
- **Login Rate Limiting**: nginx now enforces per-IP `limit_req` zones on `/auth/login`, `/auth/setup`, `/auth/change-password` (10 req/min, burst 10) and `/auth/refresh` (60 req/min, burst 30), returning 429 on excess. In proxy mode the real client IP is recovered from `X-Forwarded-For` via the realip module (trusting private-range peers only) so limits stay per-client behind an upstream proxy.
- **Refresh Token Rotation & Revocation**: Refresh tokens now carry a `jti` and are single-use — replaying a consumed token is rejected (tracked in Redis, [token_store.py](file:///home/user/Luma/backend/luma/services/token_store.py)). Logout revokes the refresh token server-side instead of only deleting cookies. A new `users.token_version` column (migration `0022`) is embedded in every JWT and bumped on password change or admin reset, instantly invalidating all outstanding sessions for that user.
- **HAE Import Token Log Hygiene**: The per-user import token embedded in the `/ingest/hae/{token}` URL is no longer written to logs — nginx disables access logging for ingest paths and a uvicorn log filter redacts the token from API access logs. Production startup warns loudly when `HAE_SHARED_SECRET` is empty.
- **Production Hardening**: Startup now refuses to boot with `ENVIRONMENT=production` if `JWT_SECRET` is a placeholder or shorter than 32 characters. Auth DB error responses return a generic message in production (operational hints stay in server logs). nginx emits `X-Content-Type-Options`, `X-Frame-Options`, and `Referrer-Policy` on all responses, plus HSTS in proxy mode. uvicorn's forwarded-IP trust is narrowed from `*` to private ranges. `/auth/setup` enforces an 8-character password minimum, family invitations can only be accepted by the invited email address, and logout deletes cookies with matching security attributes.
