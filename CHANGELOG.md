Provided a seamless mock-series fallback for day 1 users to guarantee a premium visual layout.
- **Modal Overlay Layering Bug**: Removed `zIndex: 1` from the main content container in [AppShell.tsx](file:///home/zbrain/Projects/Luma/frontend/src/components/AppShell.tsx) to prevent it from establishing an isolated local stacking context. This ensures that both the Meal Plan Slot details/replacement modal and the plan generation progress overlays correctly layer on top of the Desktop Sidebar (`zIndex: 2`) and Mobile Header, fully dimming the sidebar buttons and preventing accidental double clicks or navigation during active processes.
