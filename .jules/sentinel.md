## 2026-07-29 - Prevent Raw Exception Detail Leakage\n**Vulnerability:** Raw exception strings (`str(exc)`) were exposed to the client in HTTP 500 error responses in `backend/luma/api/insights.py`.\n**Learning:** Exception messages can contain sensitive internal state, stack traces, or database schema information, leading to Information Disclosure vulnerabilities.\n**Prevention:** Fail securely by returning generic error messages to the client and logging detailed exception traces internally using `logger.exception`.
